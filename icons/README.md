# Who Dat Icons 🦉

This folder contains icons for the Who Dat IP Resolver web application.

## Files

- `who-dat.png` - High-resolution PNG icon for web app and Linux desktop shortcuts
- `who-dat.ico` - Windows icon file for web app shortcut
- `who-dat.icns` - macOS icon file for web app bundle

## Usage

### Web Application
- **Windows**: Used for desktop shortcut "Who Dat Web.lnk"
- **macOS**: Embedded in "Who Dat Web.app" bundle
- **Linux**: Referenced in `.desktop` file for web app launcher

### CLI Tool
The CLI tool (`who-dat` command) does not use icons - power users prefer command line interface without GUI shortcuts.

## Design

- **Theme**: Matrix-inspired green owl
- **Style**: Modern, clean, recognizable
- **Format**: Optimized for each platform's requirements
- **Size**: Scalable from 16px to 512px

## Notes

- Icons are only created for the web interface
- CLI users get a terminal wrapper command instead
- All icons maintain the Who Dat branding consistency
